# 色板 token 交付格式

只交 `:root` 变量段，不要改业务选择器：

```css
:root{
  --ink-deep:#202522;   /* 主背景 */
  --bone:#D7C7A5;       /* 骨白 / 纸张 */
  --bronze:#A98B57;     /* 主操作 / 奖励 */
  --patina:#61776B;     /* 次级强调 */
  --ink:#29231e;        /* 正文（沿用现站） */
  --ink-soft:#6e6455;   /* 说明文字（沿用现站） */
}
```

验收：`04-verify` 会用 grep 检查业务 CSS 里是否残留硬编码色值。
