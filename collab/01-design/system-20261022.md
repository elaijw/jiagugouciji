# 字有骨气 · 字体与 UI 风格系统（2026-10-22）

> 这份是全站的**排版与界面规范**，不是某一页的改动记录。
> 新增页面 / 组件时先读它，再动手。落地文件：`css/type.css`（字体）、
> `css/theme.css`（令牌）、`css/ui.css` 的 WB-3 段（组件视觉唯一权威）。

---

## 0. 一句话

**纸为底，骨为物，墨为字，朱砂为动。**

整页是一张纸；照片里的骨、地图、字形是摆在纸上的**物件**（有厚度、有投影）；
字是压上去的墨；只有"要你动手"的地方才用朱砂。

四句话对应四种材质，任何新组件先问自己"我属于哪一层"，再决定底色、边、影。

## 1. 字体：四把嗓子（2026-10-22 晚修：大标题改楷）

| 角色 | 令牌 | 用在 | 为什么 |
|---|---|---|---|
| **楷（题头）** | `--font-title` | **页面级大标题**（≥28px：首屏 / 选关 / 图鉴 / 王邑 / 关卡封面） | 笔锋是圆的。宋体在大字号上"横细如发、竖粗如柱"，八个字连排就锋利；楷是"写"出来的温度 |
| **宋** | `--font-display` | 分区标题、卡片名、图版说明、大数字 | 横细竖粗，是刻刀走出来的痕迹，负责骨架 |
| **黑** | `--font-sans` | 正文、按钮、表单、导航、注释、页脚 | 界面文字不该抢戏，只负责让人读清楚 |
| **楷（引文）** | `--font-kai` | 卜辞、题记、引文（`.rw-line` / `.foot-motto` / `.bb-teach-line` / `.ac-verse`） | 「有人拿刀在骨上留了一句话」，全站只有这几处 |

**铁律：一屏之内不超过两把嗓子。** 普通页 = 楷（大标题）+ 黑（其余）；
只有带卡片名的页面（选关 / 图鉴）才出现第三把宋。

**字重一律 400。** 600 在 Windows 上会触发伪粗，宋体一伪粗就糊成一团黑——
「硬」和「脏」的真正来源不是字体族，是伪粗。

**为什么大标题不用宋**：宋体 56px 时横竖对比过头，压在纸面上像刻得有点狠，
和龟宝、和学生的距离反而远了。留宋在分区标题与数字上，骨架没丢；
大字用楷，气口就软下来。这是 2026-10-22 用户看完对照后定的方向。

**想回到宋体大标题**：`?font=song`（题头一并指回宋），不用改代码。

**兼容名**：`--font-song` / `--font-serif` / `--font-round` 全部指向上面几个，
老组件不用改。`--font-serif` 是 modes.css 里 13 处地名签条在用的旧名字。

**标题别再回到幼圆**：幼圆是"圆润的说明文字"，它让整站像儿童识字 App；
要对照就加 `?font=youyuan`。

## 2. 字号：一套阶梯，一条底线

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-micro` | 12px | 角标、图注——**全站最小，不再往下** |
| `--fs-xs` | 12.5px | 注释、元信息 |
| `--fs-sm` | 13px | 次要文字、标签 |
| `--fs-md` | **15px** | 正文基准 |
| `--fs-lg` | 17px | 导语 |
| `--fs-xl` | 21px | 小标题 |
| `--fs-2xl` | 28px | 分区标题 |
| `--fs-3xl` | 36px | 主视觉 |

语义字号（按角色取，不按大小取）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--t-display` | `clamp(36px, 4.3vw, 56px)` | 首屏主标题（8 字一行，版心 480px） |
| `--t-h1` | `clamp(28px, 2.6vw, 34px)` | 页标题 |
| `--t-h2` | `clamp(22px, 2.2vw, 28px)` | 分区标题 |
| `--t-h3` | 19px | 卡片标题 |

**底线规则**：说明性文字 ≥ 12px。仓库里还有 230 处写死在 12px 以下的字号，
分布在王邑地图针脚、贴纸角标等**受空间限制**的地方——那些是图形，可以小；
但"描述、图注、元信息"一律不许小。已在 `type.css` 第 3 节收口。

## 3. 字距与行高：中文不拉字距

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--tr-display` | `.045em` | 首屏与页标题（≥30px 才松一点，为了透气） |
| `--tr-h` | `.02em` | 分区标题、卡片标题 |
| `--tr-label` | `.14em` | **纯西文**标签（`CULTURAL GAME LAB`） |
| 正文 | `0` | 中文正文不写字距 |

混着中文的标签（`甲骨文互动叙事 / CULTURAL GAME LAB`）统一 `.06em`：
中文吃不住 .14em，一开就散架。行高：标题 1.16~1.34，正文 1.86，导语 1.9。

数字一律 `tabular-nums`（进度、统计、关卡号滚动时不会抖）。

## 4. 材质层级：四层，不许加第五层

| 层 | 是什么 | 底色 | 边 / 影 | 圆角 |
|---|---|---|---|---|
| **L0 纸** | 页面底 | `--paper` (`#f3f1e8`) | 无 | — |
| **L1 面板** | 分区、设置块、收集区 | `--sheet` (`#fffefa`) | `1px --edge` + `--sh-2` | `--r-lg` 20px |
| **L2 物件** | 关卡骨板、三步卡、字形砖 | `#f8f0dd` + `bone-surface.png` | 磕口 clip-path + 单层投影 | 由形状文件给 |
| **L3 墨块** | 弹层、拓片详情、关卡结算 | `--ink-deep` (`#241a12`) | 无描边，靠明度分离 | `--r` 14px |

判定口诀：**能拿起来的用 L2，读的是内容用 L1，挡在前面用 L3。**
L2 只能有一层投影——两层影会让"物件"飘起来，反而假。

## 5. 颜色：一个强调色就够

| 名 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 墨 | `--ink` | `#2b2318` | 正文（纸底 13.68 ✅） |
| 次墨 | `--ink-2` | `#5b4d3a` | 次要文字（7.23 ✅） |
| 淡墨 | `--ink-soft` | `#7d6b52` | 说明、占位（4.53 ✅，旧值 3.14 不达标） |
| 刻字 | `--ink-carve` | `#241d14` | 压在骨板上的字 |
| 朱砂 | `--cinnabar` | `#cc523b` | **动作**：主按钮、进度、选中 |
| 朱砂字 | `--cinnabar-tint` | `#ae4936` | 当文字用（4.88 ✅） |
| 青铜 | `--bronze` | `#a58147` | 描边、次级强调、标签 |
| 铜绿 | `--patina` | `#337663` | 状态"已完成" |

**墨要暖。** 上一版墨色是 `#273a35`（带青绿的黑），压在暖纸上像屏幕灰；
改成 `#2b2318` 之后，同一屏的观感从"发灰的网页"变成"压过的墨"。
这是本轮唯一动过的色相，其余色值沿用 tokens。

**一屏只允许一个朱砂主张。** 主按钮、进度、选中三者同时出现时，
只有最想让人点的那一个用实底朱砂，其余降为描边或文字。

## 6. 组件规则（补充 WB-3 那段）

- **按钮五档**：主（朱砂实底）/ 次（描边）/ 强烈动作（`.danger`，质问！）/
  破坏性（`.destructive`，描边反向，悬停才填实）/ 弱（文字）。
  破坏性操作用**结构差异**区分，不靠"朱砂再暗一档"——390 屏上只差明度，读不出。
- **筛选片**：`--r-pill`，未选为凹槽，选中是**淡朱砂**，不与主按钮抢眼。
- **输入框**：凹槽（`inset` 影），不用外投影——凹进去的是可以写字的地方。
- **分隔**：`1px --edge`；分区之间用刻线，不用阴影。
- **图版**（照片/地图/字形）：装裱 = 1px 界格 + 4~6px 绢距 + 贴身影 + 散影，
  四层 `box-shadow` 一次给完（见王邑小地图）。图片永不裸贴。
- **皮肤变体**（`body.carved` 这类）**禁止 `!important`**，靠前缀权重就够。

## 7. 皮肤：默认纸面，骨面是展陈模式

- 默认：**纸面**（`direction.md` 的定案：整页是纸，深墨只用于弹层/拓片/结算）。
- `?carved=1`：整页刻在甲骨上的展陈皮肤，线下大屏、图鉴讲解可用。
- `?carved=0`：仍然回纸面，老链接不会被打翻。
- `?font=mix|song|kai|sans|youyuan|noto`：只换变量，不写覆盖。

纸面/骨面是**同一套令牌的两个材质**，不是两套设计。改令牌两边同时生效。

---

## 8. 加新组件前的五问

1. 它是纸、是物、还是墨块？（定层级）
2. 它在纸上读，还是压在骨上读？（决定字色用 `--ink` 还是 `--ink-carve`）
3. 它需要人动手吗？（需要才用朱砂实底）
4. 字号落在哪一档？比 12px 小的理由是什么？
5. 一屏已经有几个朱砂、几种字体？（>1 个强调色 / >2 种字体就要减）

| 脚本 | 作用 |

| `dev/_paint_probe.js <url> <宽> <高> <选择器>` | 读"最后画成什么"：底色/影/字体/字号 |
| `dev/_cascade_probe.js <url> <选择器> <宽>` | 查"谁赢了"：按 link 顺序列出命中规则 |
