# 第二关地图 · 出图要求（风景长卷 · 物件可辨）

> 一句话：**要风景画，不是静物摆件图。**
> 和大地图同一套气质（淡墨山水长卷、骨白纸面），但画面里必须真的出现"要认的那些东西"，
> 而且每件都大到能点中——风景给气氛，物件给玩法。

---

## 一、硬性技术规格

| 项 | 要求 |
|---|---|
| 尺寸 | **2624 × 1472** px，横构图 |
| 格式 | JPEG 质量 90+，或 PNG |
| 禁止 | 任何文字、汉字、甲骨字形、印章、落款、题跋、边框、水印、UI、地图标记 |
| 禁止 | 现代物件；浓雾遮住主体；整体压得太暗；高饱和荧光色 |
| 必须 | 骨白/米黄旧绢底，淡墨与低饱和矿物色，细线勾勒 + 淡墨渲染（宋画册页感） |
| 必须 | 四边各留 ≥60px 安全边，主体不贴边、不被裁 |

## 二、构图原则（风景优先，物件落实）

1. **整张是一幅完整风景**：有天空、有地平线、有近景中景远景，能看出"这是个地方"。
2. 画里按清单放物件，**每件都要能一眼认出**：
   - 占画面宽度 **≥8%**（太小就点不中）；
   - 彼此**不重叠**、不被树石遮挡；
   - 位置按下面每张写的"大致方位"放（左/中/右、远/中/近），**不要求九宫格**。
3. 天空、水面可以大面积留白；**不要把物件挤在一起**，物件之间留出呼吸空间。
4. 视角：平视或略带俯视的长卷视角（和大地图一致），不要正俯视的沙盘感。

## 三、五张图各画什么

### ① 天象 `level2-01-sky.jpg`（4 件）

一幅**黄昏/夜晚的原野天空**长卷：夜云低垂，远处一线山影，近处是开阔的荒原。

必须出现：
- **日**：一轮**实心圆盘**（淡金偏白，边缘清楚），位于天空**中偏左上**，是画面最亮的东西
- **月**：一弯**明显的月牙**（尖端朝上或右上），位于天空**右上**，与圆盘分开、不要重叠
- **雨**：一片云下**成片的短竖线雨丝**（≥20 条），位于**中上部云脚**，看得出"在下雨"
- **火**：荒原上**一堆燃烧的篝火**（明亮火苗 + 柴堆），位于**近景下中偏右**，是画面唯一暖橙亮点

> 关键：圆盘与月牙要**同时可见且形状不同**（一个是整圆，一个是弯钩）。

### ② 山川 `level2-02-land.jpg`（9 件）

一幅**山水长卷**：左侧高峰耸立，中部大河横过，右侧远处低丘，前景河滩与田地。

必须出现：
- **山**：左侧**并列的尖峰群**（远中景），轮廓清楚
- **谷**：两座山之间的**明显 V 形凹口**（中景偏左）
- **丘**：右侧远处一个**低矮圆顶小丘**（与尖峰形成对比）
- **川**：一条**宽阔河面**自左向右**横贯中部**（画面最宽的水面）
- **水**：一条**窄的弯曲溪流**汇入大河（前景偏右，明显比川细）
- **泉**：两块石头之间**涌出的泉水**，水面有同心圆波纹（前景偏左）
- **石**：河滩上一块**孤立的大石**（前景左侧，纹理可辨）
- **土**：隆起的一堆**黄土**（前景下左，顶部平缓）
- **田**：**整齐的方格田亩**，看得见田埂分格（右下角坡地上）

> 关键：**川（宽）与 水（细）必须一眼分得出**；田要有格子感，不能画成普通草坡。

### ③ 草木 `level2-03-plant.jpg`（6 件）

一幅**河岸草木图**：一条浅溪斜穿画面，两岸植物高低错落。

必须出现：
- **木**：左侧一棵**独立的乔木**，树干、主枝、树冠完整（画面里最完整的一棵树）
- **林**：右后方**成片的树林**（多棵重叠成林，与左侧独树形成"单株/成林"对比）
- **竹**：右前方一**丛竹子**：直茎、可见竹节、细长竹叶
- **禾**：中景一株**成熟的谷子**，**穗头饱满下垂**（和竹子要分得开）
- **米**：近景地面上**一小堆散落的白米粒**，颗粒可数
- **屮**：右下角一小丛**刚出土的嫩草**（两三片叶）

> 关键：独树 / 成林 / 竹子 / 谷穗 四者形态要有明显差别，不要都画成"一团绿"。

### ④ 禽兽虫鱼 `level2-04-beast.jpg`（9 件）

一幅**水畔群兽图**：浅水滩与草岸，动物各自占据一块地方，互不遮挡。

必须出现（全部侧面轮廓清楚）：
- **鹿**：枝状角，站姿（左侧草岸）
- **牛**：双角横张，体型大（中部浅水边，画面最显眼的动物）
- **羊**：角向下弯，体型中等（中部偏右草岸）
- **豕**：**肥猪**，短腿、背有鬃（左侧岸边）
- **犬**：**狗**，尾巴上卷，体型小（右侧岸边）
- **虎**：**条纹虎**，张口（右侧石上或草丛边）
- **鱼**：两条**侧视的鱼**在浅水里，鳍尾清楚（中部水面）
- **隹**：一只**短尾小鸟**站在地上或低头啄食（右下）
- **虫**：一条**蜷曲的蛇**，可见鳞纹（右下角草丛）

> 关键：九种动物都要**各自独立**，不要合成一团；虎与犬要有明显差别（条纹 vs 卷尾）。

### ⑤ 人居器物 `level2-05-life.jpg`（12 件）

一幅**商代聚落生活长卷**：夯土城墙围着村落，河边停舟，村中有人在晾晒与制陶。

必须出现：
- **邑**：**环壕/夯土墙围起来的聚落**整体（左侧中景，看得出是一个"城"）
- **郭**：一段**独立的夯土外墙**（与邑分开，能看到夯层纹理）
- **门**：**木构城门**：两扇门板 + 门洞（城墙中部）
- **宀**：一栋**茅草顶房屋**，屋顶占主体（右下近景）
- **井**：**带木栏的水井**，井口可见（村中空地）
- **舟**：一条**独木舟**停在岸边（右下水边）
- **鼎**：**三足两耳的青铜鼎**（前景中央，器形标准，画面里最能认的器物）
- **缶**：**大腹小口**的陶罐
- **皿**：一只**浅口盘**，口沿清楚
- **酉**：**窄口深腹**的青铜酒器
- **贝**：几枚**海贝**散放，齿缝可见
- **玉**：几片**玉片/玉璧**散放，温润反光

> 关键：器物集中在前景一排（像摊开在案上），器物之间留空；城邑/城墙/城门在后景明确成型。
>
> 说明：原来这一区还有 21 个"人体类"字（目耳口止又大女小子足衣人等）。风景图里画不出这么多可点的部位，**建议这些字从本区移走**（或另做一张人物图）。

## 四、配色

- 底：骨白 / 米黄 / 旧绢（#EFE6CF ~ #D9C6A0）
- 主色：淡墨灰、赭石、青绿，**低饱和**
- 朱砂红只给「火」用，其余画面不要红
- 不要厚涂油画、不要 3D、不要动漫

## 五、负面词

```
text, letters, words, chinese characters, hanzi, kanji, calligraphy, seal, stamp,
signature, watermark, logo, ui, buttons, map pins, arrows, frame, border,
photograph, photo, 3d render, anime, cartoon, plastic, neon, oversaturated,
heavy fog covering subjects, dense mist, blurry, lowres, jpeg artifacts,
crowded, overlapping objects, cropped objects at edges, dark unreadable,
tiny objects, distant unrecognizable shapes
```

## 六、验收标准（我逐张看）

1. 尺寸 2624×1472
2. **每件清单物件都真的在画面里**，且一眼能认出（我会把它圈出来核对）
3. 物件够大（≥8% 画面宽）、不被遮挡、不被裁切
4. 没有文字/印章/水印/边框
5. 整体是**一幅完整风景**，不是把东西排成一排的静物图
6. 我按图目视标热区，逐点回读确认点得中
