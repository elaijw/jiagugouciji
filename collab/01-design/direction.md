# 视觉方向定稿（WB-1）

> 定稿日期：2026-10-22　决策人：项目 owner　执行：WorkBuddy
> 状态：**已锁死**。后续不再讨论整页底色，只按本文执行。

## 结论

**A 为主 —— 延续浅色纸面（`field-notebook.css` 这一套），青铜与朱砂只做强调色。
B 不废弃，降级为「局部深墨块」，只用在三处：弹层 / 图鉴与拓片详情 / 关卡结算。**

一句话概括：**整页是纸，深处是墨。**

## 一、为什么是 A

### 1. 三种质感全都是「局部现象」，没有一种需要整页底色

这是最关键的一条。TASK 要求判断「哪个更能承载刻痕 / 拓片 / 灯火」，逐项拆开看，会发现三者的成立条件都跟整页底色无关：

| 质感 | 成立的物理条件 | 结论 |
|---|---|---|
| **刻痕** | 刻是「在载体上减料」，凹下去的部分在光下发暗。所以刻痕 = **暗线压浅底**。 | A 天生成立。B 底上只能画亮线，亮线读作凸起或反光，**不是刻**。 |
| **拓片** | 拓片是一张纸覆在刻辞上、上墨揭下。它**永远是一张纸上的一个墨块**，从来不是一整屏黑。 | B 若做整页底，在物理上就不成立。做成弹层里的一块墨，反而比整页翻黑更真。 |
| **灯火** | 灯火是一簇火、一盏灯，是**暗处的一点亮**。它只需要周围有一圈暗，不需要整屏暗。 | A 完全能做：给灯火一个深色围合（洞窟、铸铜作坊的暗部、夜色窗格）即可。 |

所以要的东西 A 都能给，而 B 能多给的只有「整体氛围」——这一项的代价见下一条。

### 2. 线上已经是 A，且这两天的成果全部长在浅底上

`css/field-notebook.css` 是最后加载的一层，全站现役画面就是亮纸面。而最近完成的一批工作——六层骨片构件台、王邑五片小地图的绫绢装裱、61 个热区的可点视觉、六张地图的绢本淡彩——**明度、饱和度、投影方向全部按浅纸底标定**。换深底等于这批工作全部重调，不是换配色。

### 3. 已核准资产是「浅底 + 单一线宽」，B 会让它们集体失真

- 88 尊 Boss 形象（单一线宽深墨褐轮廓、无明暗无渐变、平涂骨纸底 `#efe3c8`）
- 241 条图鉴字形、全站构件与笔画字形
- 6 张地图（绢底米黄）、`assets/paper.png` 纸纹材质、首页骨片照（`oracle-bone.jpg`）

整页翻深只有两条路，**都亏**：

1. **反相** —— 线宽与「平涂」当场失真，一条 1.5px 的刻线反相后粗细观感全变，等于重画；
2. **每张图垫浅色承托块** —— 深底上到处是浅方块，比 A 更像 UI 卡片，与项目要的「文物感」正相反。

### 4. 成本对照（实际工作量，不是感受）

| 项 | A | B |
|---|---|---|
| 六张地图 | 不动 | 6 张重绘或重调明度 |
| Boss 形象 | 不动 | 88 尊重画或反相失真 |
| 图鉴字形 | 不动 | 241 条重新选色/描边 |
| 施骨片台 / 小地图装裱 | 不动 | 六层材质全部重标定 |
| 61 个热区视觉 | 不动 | 全部重调 |
| CSS 硬编码清理 | 必须做（见下） | 同样必须做，且量更大 |

两条都必须清硬编码（field-notebook 221 / modes 207 / app 60 / ui 58 处），所以这一项不构成 A 的优势，但 B 在其余五项上是净增。

## 二、B 怎么穿插（三处，有边界）

B 的两种价值——「拓片就是墨底白字」和「暗处才有灯火」——用局部深块完整保留。

### 合法位置

| # | 位置 | 用 B 的理由 | 用哪组令牌 |
|---|---|---|---|
| 1 | **弹层 / 认字卡 / 构形讲解** | 盖在纸面上的那一张「墨」；解开一个字就是揭开一张拓片 | 底 `--rub` → `--ink-deep`，字 `--on-dark`，描边 `--ink-deep-line` |
| 2 | **图鉴详情、拓片预览** | 这里本来就是在看拓片，深底是内容本身而非装饰 | 同上 |
| 3 | **关卡结算 / 成就** | 一屏之内、有终点感，适合关灯；也压得住 Boss 形象的深轮廓 | 同上，允许 `--bronze` 做金线 |

### 红线（写死，不做例外）

1. **深墨块不得充当任何页面底**。页面级 `body` / `.sheet` / `.home` 一律 `--bone`。
2. **深墨块内不得出现 `--bone` 一族的浅底大面**。需要承托时用 `--ink-deep-2`，否则深底上会浮出一堆浅方块，回到被否掉的「UI 卡片」观感。
3. **深墨块面积不得超出一屏的三分之一**。它是转场与停顿，不是常态。
4. **拓片只用在「已经认得这个字」的场合**（图鉴、结算、回看），**不用在「正在学」的场合**（第一关构字、第二关热区）。学的时候要的是刻，看完之后才给拓。
5. 深墨块进出用 `opacity` + `transform`，≤1.5s，并尊重 `prefers-reduced-motion`。

### 一句方便记的口径

> **学的时候是刻（纸面 + 暗线），学会了是拓（墨底 + 亮线）。**

这条同时解释了为什么 A 做主、B 做副：它是教学流程的两个阶段，不是两套皮肤。
